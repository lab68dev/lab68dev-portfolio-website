# LAB68 Portfolio

A modern, minimalist portfolio website showcasing selected projects and development work.

## Overview

This portfolio is built with Next.js and features a cyberpunk-inspired design aesthetic with custom animations and interactive elements. The site presents a curated collection of projects with detailed information about each one, including live demos and source code repositories.

## Features

- Responsive design optimized for all devices
- Dark mode with custom theme implementation
- Smooth scroll animations using Framer Motion
- Project showcase with filterable categories
- Interactive terminal-style interface elements
- Custom cursor animation
- Performance-optimized with Next.js 14

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Structure

The portfolio is organized into several key sections:

- Hero section with introduction and primary call-to-action
- Projects showcase featuring selected works with detailed descriptions
- About section highlighting skills and experience
- Contact section for professional inquiries

## Projects Featured

Each project entry includes:
- Project title and category
- Brief description
- Technology stack used
- Links to live demo and source code
- Custom background imagery

## Design Philosophy

The design follows a brutalist, minimalistic approach with cyberpunk influences. Typography is bold and statement-heavy, with generous use of uppercase text and monospace fonts for technical elements. The color scheme relies on high contrast with accent colors highlighting interactive elements.

## Performance

Built with performance in mind, the site leverages Next.js features including:
- Server-side rendering for optimal initial load
- Image optimization with next/image
- Code splitting and lazy loading
- Static generation where possible
